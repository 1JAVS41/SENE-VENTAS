# SENE.VENTAS - Android nativo
Aplicación Android nativa en Kotlin. Guarda productos, ventas, movimientos y turno localmente.
## Compilar
GitHub Actions ejecuta **Compilar APK SENE.VENTAS** al subir cambios a la rama de reconstrucción. Descarga el artefacto **SENE-VENTAS-APK** desde la ejecución.
## Datos
Las ventas y el inventario funcionan sin internet. La hora de internet y WhatsApp requieren conexión. PIN inicial de patrón: 2910.
