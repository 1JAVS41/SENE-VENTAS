# SENE.VENTAS - Android nativo
Aplicación Android nativa en Kotlin. Guarda productos, ventas, movimientos y turno localmente.
## Compilar
El flujo de GitHub Actions **Compilar APK SENE VENTAS** se ejecuta al subir cambios a `main` y a las ramas de reconstrucción. También permite ejecución manual desde la pestaña Actions. Descarga el artefacto **SENE-VENTAS** desde la ejecución completada.
## Datos
Las ventas y el inventario funcionan sin internet. La hora de internet y WhatsApp requieren conexión. PIN inicial de patrón: 2910.

## Reportes para SENE ADMIN
Los reportes cifrados enviados por WhatsApp muestran la indicación `*COPIA Y PEGA en SeneAdmin*`. Incluyen los datos del trabajador y su jornada, inventario, ventas y correcciones, gastos y movimientos, y las solicitudes pendientes de préstamo o consumo.
